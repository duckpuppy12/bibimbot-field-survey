1 사진 찍고 이름 찾기

앨범에서 고르기

누르면 앨범·파일·카메라 중에서 고를 수 있다.

긴 변 1600px로 줄인 사본만 앱에 저장한다. 휴대폰의 원본 사진은 그대로 남는다.

잘 못 맞힐 때 — 이렇게 찍으면 올라간다
  • 꽃 → 열매 → 잎 순으로 잘 맞힌다. 줄기·껍질은 다른 데가 안 보일 때만.
  • 한 부위를 화면 가득 채운다. 풀밭 전체를 멀리서 찍으면 거의 못 맞힌다.
  • 같은 포기를 여러 장(최대 5장) 찍어 두고 한 번에 보낸다. 부위를 섞어도 좋다.
  • 초점을 맞추고 흔들리지 않게. 800×800보다 작으면 성능이 보장되지 않는다.

그래도 안 되면 사진을 렌즈·다른 앱으로 보내기로 Google 렌즈에 보내 확인한 뒤, 이름을 복사해 2단계에 붙여 넣는다. 렌즈 결과가 앱으로 자동으로 돌아오지는 않는다.

Pl@ntNet이 학명 후보를 돌려주면 비빔봇 도감과 맞춰 아래 2단계에 올린다. 누르면 첨부한 사진이 Pl@ntNet 서버로 전송된다. 사람 얼굴이나 차량 번호가 찍힌 사진은 보내지 않는다. 결과는 후보일 뿐이므로 이름은 학생이 확정한다.

2 이름 확정

    잘 안 될 때: Google 렌즈로 확인하기

    비빔봇은 렌즈 결과를 자동으로 받아오지 못한다. 렌즈에서 이름을 확인한 뒤 이 앱으로 돌아와 위 칸에 붙여 넣어야 한다. 사진 식별이 안 될 때만 쓴다.

    1. 휴대폰에서 Google 앱(또는 Chrome 검색창)을 연다.
    2. 검색창 오른쪽 카메라(렌즈) 아이콘을 누른다.
    3. 식물을 화면에 담고 촬영해 이름 후보를 확인한다.
    4. 이름을 길게 눌러 복사한 뒤 이 앱으로 돌아와 위 칸에 붙여 넣는다.

    앱으로 돌아오는 방법: 홈 화면에서 브라우저를 다시 열거나, 최근 앱 목록에서 이 화면을 선택한다.

    렌즈를 켜 둔 채로 기록하려면 (Android)

    1. 최근 앱 버튼 → 비빔봇 아이콘 길게 누르기 → 화면 분할을 고른다.
    2. 위쪽에 Google 앱(렌즈), 아래쪽에 비빔봇을 둔다.
    3. 렌즈로 이름을 확인하고, 아래 비빔봇에서 빠른 기록 버튼만 누르면 된다.

    화면 분할을 쓰지 않아도, 앱을 벗어났다 돌아오면 고른 식물과 메모는 그대로 남아 있다. iPhone Safari에는 화면 분할이 없어 앱을 번갈아 전환해야 한다.

    사진 여러 장 한 번에 올리기

    휴대폰 기본 카메라로 찍은 사진에는 찍은 자리의 좌표가 들어 있다. 현장에서는 찍기만 하고, 돌아와서 한 번에 올리면 좌표가 그대로 핀이 된다.

    누르면 앨범이 열린다. 여러 장을 한 번에 고를 수 있다.

    좌표가 없다고 나올 때
    • 카메라 위치 태그가 꺼져 있으면 사진에 좌표가 안 들어간다. Android는 카메라 앱 설정 → 위치 태그, iPhone은 설정 → 개인정보 보호 → 위치 서비스 → 카메라에서 켠다.
    • 메신저로 주고받은 사진은 좌표가 지워진다. 원본 파일을 그대로 올려야 한다.
    • 앱 안 카메라로 찍은 사진에는 좌표가 없다. 그건 찍는 즉시 기록되므로 여기에 올릴 필요가 없다.
    • 실내나 지하에서 찍으면 좌표가 안 잡혔을 수 있다.

      사진 자동 식별 (Pl@ntNet)

      키 받는 순서

      1. my.plantnet.org에서 무료 계정을 만든다(1인 1계정).
      2. 로그인한 뒤 my.plantnet.org/settings/api-key 로 들어가 개인 API 키를 생성한다.
      3. 같은 화면에서 "expose my API key"를 체크한다. 브라우저에서 쓰려면 이게 켜져 있어야 한다.
      4. Authorized domains에 이 앱의 주소를 한 줄에 하나씩 넣는다. (예: duckpuppy12.github.io)
      5. 키를 이 칸에 붙여 넣고 저장한다.

      무료는 하루 500건이고 실패한 요청도 1건으로 차감된다. 교육·비영리 용도는 상향을 요청할 수 있으나 "powered by Pl@ntNet" 표기가 조건이다. 허용 도메인을 걸어 두면 키가 보이더라도 다른 사이트에서는 쓰지 못한다. 앱 주소가 바뀌면 허용 도메인도 다시 넣어야 한다. 키는 내보내기 파일과 보고문에 들어가지 않는다.

      선택 · Google 지도로 바꾸기

      보통은 이 칸을 비워 둔다

      지도 탭은 기본으로 OpenStreetMap을 쓴다. API 키도 결제 계정도 필요 없다. Google 지도는 사용량이 적어도 키와 결제 계정 연결이 반드시 필요하고, 월 $200 무료 크레딧은 2025년 2월 28일로 끝났다. 위성 사진처럼 Google 지도가 꼭 필요할 때만 넣는다.

      키를 넣기 전에 확인할 것

      1. Google Cloud에서 Maps JavaScript API 활성화
      2. 프로젝트에 결제 계정 연결
      3. 키에 웹사이트(HTTP 리퍼러) 제한으로 이 앱의 HTTPS 주소만 허용
      4. 키에 API 제한으로 Maps JavaScript API만 허용
      5. 예산 알림과 함께 할당량도 설정 (예산 알림만으로는 지출이 멈추지 않는다)

      브라우저용 지도 키는 네트워크 요청에서 확인될 수 있다. 이 기기에 저장하는 것만으로 비밀이 되지 않으므로 도메인 제한과 API 제한을 반드시 적용한다. 키는 내보내기 파일과 보고문에 들어가지 않는다. 무료로 쓸 수 있다고 보장하지 않으며, 요금은 Google의 현재 정책을 직접 확인한다.

      위치 권한 도움말

      • HTTPS 주소에서만 위치 권한을 요청할 수 있다.
      • Android Chrome: 주소창 왼쪽 자물쇠 → 권한 → 위치 → 허용.
      • iPhone Safari: 설정 → Safari → 위치 → 확인, 그리고 설정 → 개인정보 보호 → 위치 서비스 켜기.
      • 권한을 거부해도 지도에서 직접 좌표를 고르면 기록할 수 있다.

      정확도 기준 (현장 시험으로 조정)

      중복 확인 반경은 이번 측정 정확도와 비교해 큰 쪽이 적용된다. 휴대폰 GPS 오차가 보통 3~10m이고 하천변·나무 밑에서는 더 커지기 때문이다. 반경을 1m처럼 오차보다 작게 두면 같은 포기를 다시 찍어도 '다른 자리'로 들어와 중복을 못 막는다. 실제 측정값을 보고 조정한다.

      데이터 저장과 백업

      기록과 사진은 서버가 아니라 이 기기의 브라우저 저장소(IndexedDB)에 남는다. 브라우저 데이터를 지우면 함께 사라지므로 조사가 끝나면 JSON 백업을 내려받는다.

      선택 기능 · 자체 AI 모델

      사진 자동 식별은 Pl@ntNet 하나만 쓴다. Teachable Machine 같은 팀 자체 모델은 넣지 않았다. 닫힌 분류기라 학습시키지 않은 식물을 만나면 "모르겠다"가 아니라 가장 비슷한 것을 골라 버리는데, 그 오답이 토종 판정으로 이어지면 위험하기 때문이다. 데이터 구조에는 team-model 값을 남겨 두어 나중에 붙일 수는 있다.

      개인정보

      • 이름·학번·연락처를 받지 않는다.
      • 위치와 사진은 이 기기에만 저장되고, 내보낼 때만 밖으로 나간다.
      • 사람 얼굴이나 차량 번호가 찍힌 사진은 공유 전에 교사가 확인한다.
      • 도감 참고 그림은 팀이 직접 그린 도식이며 출처와 라이선스를 도감에 적어 둔다.
