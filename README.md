# 토종 지킴이 비빔봇 · 현장조사 웹앱

완산 발명센터 FLL 팀 ‘전주비빔밥’이 외래 식물을 조사하고, 위험도와 발견 위치를 함께 기록하는 모바일 웹앱.
`FLL-비빔봇-웹앱-PRD.md` v1.0을 구현한 것이다.

흐름: **사진 찍기 → Pl@ntNet이 이름 후보 → 비빔봇 도감으로 판정 → GPS 좌표 기록 → 지도 핀 → 내보내기**

PRD 3절은 Google 렌즈를 주 경로로 잡았지만, 렌즈에 공개 API가 없어 결과를 자동으로 받아올 수 없다.
그래서 **사진 식별은 Pl@ntNet, 지도는 OpenStreetMap**으로 바꿨다. 둘 다 앱 안에서 끝나고
복사·붙여넣기가 필요 없다. 렌즈는 사진 식별이 안 될 때 쓰는 보조 수단으로 2단계 안에 접어 두었다.

## 실행

```bash
node tools/serve.js 5173
```

브라우저에서 `http://localhost:5173`. 위치 권한과 IndexedDB는 `file://`에서 막히므로 로컬 확인도 http로 연다.
실제 배포는 **정적 HTTPS 호스팅**에 이 폴더를 그대로 올리면 된다. 빌드 과정이 없다.

### 배포처: Firebase Hosting을 권한다

GitHub Pages도 되지만 Firebase Hosting이 이 프로젝트엔 더 맞는다.

- 무료(Spark) 플랜으로 **고정 HTTPS 주소**(`https://프로젝트이름.web.app`)가 나온다.
  지금 쓰는 임시 터널처럼 주소가 바뀌지 않는다.
- **Firebase 프로젝트는 곧 Google Cloud 프로젝트다.** 같은 프로젝트에서 Maps JavaScript API를 켜고
  키를 만들 수 있어 관리가 하나로 묶인다. (단, Maps는 그 프로젝트에 **결제 연결이 필수**다.
  Firebase 무료 플랜과는 별개 문제다.)
- 배포 주소가 고정되니 **키의 HTTP 리퍼러 제한을 제대로 걸 수 있다.** 임시 터널로는 못 한다.

```bash
npm install -g firebase-tools
firebase login
firebase init hosting     # public 폴더로 이 폴더(.)를 지정, SPA 재작성은 아니오
firebase deploy
```

**Cloud Functions는 유료(Blaze) 플랜이 필요하다.** Pl@ntNet 키를 서버 뒤로 숨기려면 Functions가
필요한데, 그러려면 결제를 붙여야 한다. 지금은 키를 교사 기기에만 넣는 방식이라 Functions 없이 돌아간다.
Firestore로 여러 기기 기록을 모으는 것은 PRD가 MVP 밖으로 뺀 항목이다.

## 교사가 먼저 할 일

### A. Google 지도 키 — **대부분 필요 없다**

지도 탭은 기본으로 **OpenStreetMap**(Leaflet)을 쓴다. **API 키도 결제 계정도 필요 없다.**

Google 지도는 사용량이 적어도 공짜가 아니다. 공식 문서 기준으로 **모든 요청에 API 키가 필요하고
프로젝트마다 결제를 활성화해야 하며**, 월 $200 무료 크레딧은 **2025년 2월 28일로 끝났다**.
위성 사진처럼 Google 지도가 꼭 필요할 때만 아래 절차를 밟는다.

<details>
<summary>그래도 Google 지도를 쓰려면</summary>

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 로그인하고 **프로젝트를 만든다.**
2. **결제 계정을 그 프로젝트에 연결한다.** 좌측 메뉴 **결제(Billing)** → 계정이 없으면
   **결제 계정 관리(Manage Billing Accounts)**에서 새로 만든다. Maps는 결제 연결이 **필수**다.
3. **API를 켠다.** 콘솔에서 Maps JavaScript API 제품 페이지를 열고 **사용(Enable)**.
   켠 뒤 몇 분은 기다린다.
4. **키를 만든다.** **Google Maps Platform → Keys & Credentials** →
   **사용자 인증 정보 만들기(Create credentials) → API 키**.
   만들 때 뜨는 **Select API restrictions**에서 **Maps JavaScript API만** 남긴다.
5. **키를 제한한다.** 키 편집 화면에서
   - **애플리케이션 제한 → 웹사이트(HTTP 리퍼러)** → 배포 주소를 넣는다 (예: `https://내앱주소/*`)
   - **API 제한 → Maps JavaScript API** 선택 후 저장
   제한 없는 키는 아무 서비스에나 쓸 수 있고 **남용 요금은 키 주인이 문다.**
6. **예산 알림과 함께 할당량(Quotas)도 건다.** 예산 알림만으로는 지출이 멈추지 않는다.
7. 앱 **설정 탭**에 키를 붙여 넣는다.

테스트만 할 거라면 결제 없이 쓰는 **Maps Demo Key**도 있다(프로토타이핑 전용, 기능 일부만).

</details>

### A-2. OpenStreetMap을 쓸 때 지킬 것 (기본값)

[OSM 타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 코드에서 이미 지키고 있다.
고칠 때 깨뜨리지 말 것.

- **저작자 표시를 지우지 않는다.** 지도 오른쪽 아래 "© OpenStreetMap 기여자"는 숨기거나 접으면 안 된다.
- `https://tile.openstreetmap.org/{z}/{x}/{y}.png` 만 쓴다(http 금지).
- **미리 받기·대량 내려받기를 하지 않는다.** 지도 타일 오프라인 캐싱은 그래서 지원 범위 밖이다.
- 캐시 헤더를 그대로 따른다. 타일 서버는 기부로 운영되고 SLA가 없다.

### B. Pl@ntNet 키 (사진 자동 식별에 쓴다 — 없어도 이름 직접 입력은 된다)

1. [my.plantnet.org/signup](https://my.plantnet.org/signup)에서 **무료 계정**을 만든다(1인 1계정).
2. [my.plantnet.org/settings/api-key](https://my.plantnet.org/settings/api-key)에서 **개인 API 키를 생성**한다.
3. 같은 화면에서 **"expose my API key"를 체크**한다. 브라우저(이 앱)에서 호출하려면 필수다.
4. **Authorized domains**에 앱 주소를 **한 줄에 하나씩** 넣는다. (서버에서도 쓸 거면 Authorized IPs)
5. 앱 **설정 탭**에 키를 붙여 넣는다.

하루 500건(실패도 차감), 동시 20건. 교육·비영리 상향은 요청 가능하되 "powered by Pl@ntNet" 표기가 조건이다.

> **앱 주소가 바뀌면 3~4번을 다시 해야 한다.** 임시 터널처럼 주소가 도는 환경에서는 매번 고쳐야 하므로,
> 사진 식별을 쓸 거라면 **고정 주소(정적 호스팅)를 먼저 잡는 편이 편하다.**

브라우저용 키는 네트워크 요청에서 확인될 수 있다. 이 기기 저장만으로 비밀이 되지 않으므로 도메인·API 제한이 필수다.
키는 소스·내보내기 파일·보고문 어디에도 들어가지 않는다. 키가 없거나 인증에 실패하면 지도 대신 **간이 좌표판**이
뜨고, 이름 확인·기록·내보내기는 그대로 작동한다.

## 도감 재검증 (2026-10-27)

법정 생태계교란 **식물은 18종**이다 — 환경부고시 제2023-228호의 17종 + 2024년 10월 31일 신규 지정된
**물여뀌바늘**(*Ludwigia peploides*). 용인시 공식 포털의 고시 표와 위키백과 지정 연도표가 서로 일치했고,
2025~2026년 추가 지정은 확인되지 않았다.

초안에서 고친 것:

- **환삼덩굴 추가** — 2019년 지정. **토종인데 지정된 종**이라 PRD 7절의 "토종이어도 지정이면 빨강 우선"이
  실제로 작동하는 사례다. 초안은 토종·비지정(초록)으로 잘못 넣고 있었다.
- **물여뀌바늘 추가** — 2024년 지정, 수생식물.
- **고시 학명 표기를 별칭에 추가** — 미국쑥부쟁이 `Aster pilosus`, 가시상추 `Lactuca scariola`,
  서양등골나물 `Eupatorium rugosum`, 서양금혼초 `Hypochoeris radicata`,
  물참새피 `Paspalum distichum var. distichum`, 돼지풀 `Ambrosia artemisiaefolia var. elatior`.
  고시 표기로 검색해도 찾아진다.
- 종마다 **지정 연도**를 특징 설명에 넣었다.

검증 상태(`verificationStatus`):

- **지정 18종 → `verified`** (화면에 '검토 필요' 배지가 붙지 않는다)
- **나머지 15종 → `needs-review`** — 지정 목록에 없다는 것은 확인했지만 **토종/외래 구분은 공식 대조 전**이다.
  즉 빨강인지 아닌지는 검증됐고, 초록인지 노랑인지는 아직 아니다.

대회 전 국가법령정보센터의 고시 원문으로 한 번 더 대조한다.

## 판정 규칙

| 분류 | 표시 | 행동 안내 |
|---|---|---|
| 생태계교란 생물 | ▲ 빨강 | 담당자에게 현장 확인·제거 검토 요청 |
| 지정되지 않은 외래 식물 | ◆ 노랑 | 분포와 확산 관찰 |
| 토종 식물 | ● 초록 | 서식지 보호 |
| 확인 필요 | ■ 보라 | 교사·전문가와 이름·분류 확인 |

- 지정 생물이면 토종 여부보다 **지정 여부가 먼저**다. 환삼덩굴이 바로 이 경우다(토종 + 지정 → 빨강).
- 목록에 없는 이름은 **절대 토종으로 자동 처리하지 않는다**. ‘확인 필요’로 남는다.
- ‘제거 완료’는 처리 상태일 뿐, 식물 분류를 덮어쓰지 않는다(지도 핀만 회색).
- 저장 시 **판정 스냅샷**(`categorySnapshot`, `catalogVersion`)을 남기므로, 나중에 도감을 고쳐도 과거 기록의 판정은 바뀌지 않는다.

## 데이터

기록·사진은 서버 없이 이 기기의 **IndexedDB**(`bibimbot-field`)에 저장된다. localStorage는 지도 키·임계값 등 작은 설정과
기존 `bibimbot-field-v2` 마이그레이션에만 쓴다. 브라우저 데이터를 지우면 함께 사라지므로 조사 후 JSON 백업을 받는다.

- **CSV** — UTF-8 BOM, 쉼표/줄바꿈/따옴표 이스케이프, 엑셀 수식 해석 방지(`=`로 시작하는 값 앞에 `'`). 사진 미포함.
- **GeoJSON** — FeatureCollection, 좌표 순서 **[경도, 위도]**. 사진 바이너리·API 키 제외.
- **JSON 백업** — `schemaVersion`·도감 버전·사진 포함 여부 명시. 복원 전 형식·좌표 범위·열거형을 검사하고, 실패하면 아무것도 바꾸지 않는다.

## 빠른 기록 (걸어다니며 연속으로 찍기)

종을 한 번 확정하면 **빠른 기록** 카드가 뜬다. 큰 버튼 한 번 = 위치 재측정 + 즉시 저장이고,
같은 종이 가까이 이미 기록돼 있으면 **묻지 않고 건너뛴다**. 사진·메모가 필요한 건만 아래 단계로 저장한다.

- 앱을 벗어났다 돌아와도 **고른 종과 메모는 그대로 남는다**(12시간). 좌표는 오래되면 위험하므로 다시 잰다.
- Android는 화면 분할로 위에 Lens, 아래에 비빔봇을 두고 쓸 수 있다. 안내가 조사 탭에 들어 있다.
- 렌즈에서 복사한 이름은 **붙여넣기** 버튼 한 번으로 들어간다.

### 중복 반경을 1m로 두면 안 되는 이유

휴대폰 GPS 오차는 보통 3~10m이고 하천변·나무 밑에서는 더 커진다. **반경이 오차보다 작으면
같은 포기를 다시 찍어도 좌표가 몇 m 튀어서 '다른 자리'로 들어온다** — 막으려던 중복이 그대로 들어온다.
반대로 1m 떨어진 두 포기는 GPS로 아예 구분되지 않는다.

그래서 적용 반경은 **설정값과 이번 측정 정확도 중 큰 쪽**이다. 정확도 6m면 8m(설정값)가,
정확도 30m면 30m가 적용된다. 건너뛸 때 화면에 "적용 반경 Nm (이번 정확도 약 Mm)"으로 같이 보여 준다.
야외에서 실제 정확도를 보고 설정 탭에서 조정한다.

## 사진 자동 식별 (Pl@ntNet)

조사 탭 3단계에서 사진을 붙이고 **사진으로 이름 찾기**를 누른다. 후보가 2단계 목록에 올라오고,
**이름 확정은 학생이 한다.** 자동으로 확정하지 않는다.

- 보내는 것: 저장용으로 줄인 사본 최대 5장 + 찍은 부분(잎/꽃/열매/껍질/자동)
- 받는 것: 학명 + 일치도(0~100%) + 일반명 + 오늘 남은 횟수
- 도감 연결: Pl@ntNet의 **학명**을 도감의 `scientificName`·별칭과 **정확 일치**로만 맞춘다.
  느슨하게 맞추면 엉뚱한 종으로 이어지기 때문이다.
- **도감에 없는 학명은 '확인 필요'(보라)로 남는다.** 절대 토종으로 단정하지 않는다.
- 일치도가 30% 미만이면 후보에 **확신 낮음** 배지가 붙는다.
- 이렇게 고른 기록은 `identificationMethod: 'photo-api'`로 저장되어 CSV·GeoJSON·백업에 그대로 남는다.
  (PRD 8절의 세 값에 더한 네 번째 값이다.)

**사진이 외부로 나간다.** 버튼을 눌렀을 때만 전송되고, 화면에도 그렇게 적어 두었다.
사람 얼굴·차량 번호가 찍힌 사진은 보내지 않는다.

자체 모델(Teachable Machine)은 **넣지 않았다.** 닫힌 분류기라 학습시키지 않은 식물을 만나면
"모르겠다"가 아니라 가장 비슷한 것을 골라 버리고, 그 오답이 토종 판정으로 이어지면 위험하다.

## 지도 백엔드 3단계

| 순위 | 백엔드 | 조건 | 쓸 수 있는 것 |
|---|---|---|---|
| 1 | **OpenStreetMap** (기본) | 없음 — 키도 결제도 불필요 | 핀, 내 위치·정확도 원, 탭해서 좌표 지정, 필터 |
| 2 | **Google 지도** | 설정 탭에 키 입력 (+ 결제 연결) | 위와 같음 |
| 3 | **간이 좌표판** | 위 둘 다 실패(인터넷 끊김 등) | 거리 눈금·방위가 있는 배치도, 핀 선택, 탭해서 좌표 지정 |

키를 넣었는데 Google이 실패하면 **OSM으로 내려가고** 교사에게 원인 안내를 띄운다. 지도가 안 떠도
기록·판정·내보내기는 모두 그대로 된다.

### 인터넷이 끊겼을 때 (간이 좌표판)

**GPS는 인터넷 없이도 된다.** 위성 신호라서 데이터가 끊겨도 좌표는 그대로 잡힌다.
끊겨서 못 쓰는 것은 **지도 그림과 사진 자동 식별뿐**이고, 조사·빠른 기록·저장·내보내기는 다 된다.
화면에도 그렇게 적어 둔다.

그래서 간이 좌표판을 눈으로 읽을 수 있게 만들었다.

- **거리 눈금(m)** — 핀 사이 간격을 실제 거리로 가늠한다. 보이는 범위에 맞춰 자동으로 1·2·5·10…m를 고른다
- **방위 표시(N)** 와 격자
- **내 위치**(파란 점)와 **정확도 원**
- **좌표 지정 모드에서 좌표판을 탭하면** 그 자리의 위도·경도가 조사 화면으로 넘어간다
- 핀을 탭하면 기록 상세가 열린다
- 인터넷이 **돌아오면 자동으로 지도를 다시 불러온다**(`online` 이벤트)

지도 타일을 미리 받아 두는 오프라인 캐싱은 **하지 않는다.** OSM 타일 정책이 사전 내려받기를 금지하고,
PRD 13절도 지원 범위 밖으로 두었다. 다만 한 번 본 영역은 브라우저 캐시에 남아 다시 보일 수 있다(보장은 아님).

## 기록을 Google 지도 앱에서 보는 방법

1. **앱 안의 지도 탭** — 위 표 참고. 기본은 OpenStreetMap이다.
2. **기록 하나를 휴대폰 지도 앱으로** — 기록 상세의 **구글맵에서 열기** 버튼이
   `https://www.google.com/maps/search/?api=1&query=위도,경도`를 연다. **API 키가 필요 없다.**
   길찾기나 다른 사람에게 위치 공유할 때 쓴다.
3. **전체 기록을 Google 내 지도(My Maps)로** — 내보낸 **CSV를 그대로 가져오기** 하면 된다.
   CSV에 `위도`·`경도` 열이 있어 My Maps가 핀으로 찍고, `분류` 열로 색을 나눌 수 있다. 키가 필요 없고
   담당자에게 지도 링크로 공유하기도 좋다. GeoJSON은 geojson.io·QGIS에서 연다.

## 좌표 기준 (설정 탭에서 조정)

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 정확도 경고 | 50 m | 넘으면 재측정/수동 선택 안내 |
| 좌표 유효 시간 | 30 초 | 지나면 재측정 권장 |
| 중복 확인 반경 | 8 m | 같은 이름이 이 안에 있으면 중복 확인 (실제로는 측정 정확도와 비교해 큰 쪽) |

경고가 떠도 학생이 확인하면 저장되며, 그 정확도 값이 그대로 남는다. **실내 시연 좌표(`demo`)는 모든 화면과
내보내기에서 ‘시연 기록’으로 표시**되고 실제 현장 GPS로 위장하지 않는다.

## 확인한 것 / 확인하지 못한 것

데스크톱 크롬(360px 에뮬레이션)에서 확인:

- 이름 검색 → 판정 → 좌표 → 저장 → 새로고침 후 복구
- 가시박·단풍잎돼지풀·미국쑥부쟁이 = 빨강, 쑥부쟁이 = 초록, 목록 밖 이름 = 확인 필요
- GPS 권한 거부·타임아웃 시 수동 선택 안내, 수동/시연 좌표가 내보내기에서 구분됨
- CSV BOM·이스케이프·수식 방지, GeoJSON [경도, 위도], 백업 검증(잘못된 좌표 거부)
- 8m 중복 탐지, 제거 완료 상태가 분류를 덮지 않음
- 360px에서 가로 스크롤 없음, 44px 미만 터치 영역 없음
- 실제 Android 휴대폰(HTTPS 터널)에서 화면이 뜨고 터치가 먹는 것까지 확인

### 주의: `hidden` 속성과 CSS `display`

`[hidden] { display: none !important; }`를 `styles.css` 맨 위에 둔 이유가 있다. 브라우저 기본
스타일의 `[hidden]{display:none}`은 우선순위가 낮아서, 어떤 클래스에 `display:flex` 같은 값을 주면
`hidden`이 걸려 있어도 그 요소가 화면에 남는다. 실제로 `.dialog-backdrop`이 그랬고, **빈 확인
대화상자가 늘 떠서 화면 전체를 덮고 모든 터치를 막는** 버그가 났다. 데스크톱에서 JS로만 조작하면
드러나지 않고 실기기에서야 보인다. 새 오버레이를 만들 때 이 규칙을 지우지 말 것.

OpenStreetMap 지도는 HTTPS 실환경에서 확인했다: 타일 로드, 저작자 표시, 분류색 핀, 지도를 탭해
좌표를 고르면 조사 화면으로 넘어오는 것까지.

Pl@ntNet 연동은 가짜 응답으로 확인했다: 후보 렌더링·일치도·확신 낮음 배지·남은 횟수 표시,
학명→도감 판정 연결, 도감에 없는 종의 '확인 필요' 처리, 401/404/413/429/500/네트워크 오류 메시지,
`photo-api`가 CSV·GeoJSON·백업 검증을 통과하는 것.

**아직 하지 않은 것** (PRD 14절 수용 기준):

- **실제 Pl@ntNet 키로 실제 사진 식별** — 한국 자생종 인식률이 실제로 어떤지 확인 필요
- 실제 제한된 Google 지도 키로 Google 백엔드 확인 (OSM 백엔드는 실기기 HTTPS에서 확인함)

- 실제 Android Chrome / iPhone Safari 기기 시험
- 실제 제한된 API 키로 Google 지도 로드·오류 분기 확인
- 야외 GPS 정확도 측정, 50건 규모 시험
- HTTPS 배포
- 비지정 15종의 **토종/외래 구분** 공식 대조 (지정 여부는 위에서 검증 완료)
- 국가법령정보센터 고시 **원문**으로 지정 목록 최종 확인

도감 참고 그림 4종은 팀이 직접 그린 SVG 도식(CC0)이며 사진이 아니다. 식별 보조용이고 정답을 보장하지 않는다.

## 범위 밖

로그인, 실시간 공동지도, 서버 자동 신고, EV3 원격 제어, 자동 제거, 드론, **Lens 결과 자동 수집**,
지도 타일 오프라인 캐싱. 자체 AI 모델(Teachable Machine)은 P2로 아직 들어 있지 않다.

### Lens 자동 연동이 왜 범위 밖인가 (2026-10-27 재확인)

Google은 **Lens의 공개 API를 제공하지 않는다.** third-party가 Lens 결과를 받아올 공식 경로가 없고,
Google 개발자 포럼도 "Lens와 같은 기능·성능을 내는 공개 Cloud 서비스는 현재 없다"고 답한다.
시중의 "Google Lens API"는 전부 **비공식 스크래퍼**라 약관 위반·중단 위험이 있어 학생 대회용으로 쓰지 않는다.
Cloud Vision은 별도 제품이고 식물 동정 결과를 보장하지 않는다.

**사진 자동 식별 자체는 가능하다.** Lens가 아니라 식물 동정 전용 API를 쓰는 길이다.

### Pl@ntNet API 타당성 확인 (2026-10-27, 실제로 찔러본 결과)

| 항목 | 확인 결과 |
|---|---|
| 엔드포인트 | `POST https://my-api.plantnet.org/v2/identify/{project}` (`project`는 `all`) |
| 요청 | `api-key`(쿼리), `images`(최대 5장·합계 50MB), `organs`(leaf/flower/fruit/bark/auto), `lang`, `nb-results` |
| 응답 | `results[].species.scientificNameWithoutAuthor`, `score`(0~1), `commonNames`, 잔여 할당량 `remainingIdentificationRequests` |
| **CORS** | **열려 있다.** 브라우저에서 직접 호출해 401 응답 본문까지 읽혔다 → 서버·프록시 없이 호출 가능 |
| 무료 한도 | 1일 500건. 실패한 요청도 1건으로 차감된다. 동시 요청 20개 |
| 교육용 | 비영리 플랜으로 상향 요청 가능. 단 "powered by Pl@ntNet" 표기 필수 |
| 계정 | 무료 계정 가입 필요(1인 1계정). **교사가 직접 가입해야 한다** |
| 키 보호 | **도메인 제한 가능.** 설정에서 "expose my API key" + Authorized domains |

**도감 연결은 이미 된다.** Pl@ntNet은 학명을 돌려주고 우리 도감은 `scientificName`을 갖고 있어 그대로 이어진다.
모의 응답으로 확인한 결과: `Sicyos angulatus`→가시박(빨강), `Symphyotrichum pilosum`→미국쑥부쟁이(빨강),
`Humulus japonicus`→환삼덩굴(빨강), `Aster yomena`→쑥부쟁이(초록), 도감에 없는 종→**확인 필요(보라)**.
즉 사진 한 장에서 판정까지 자동으로 이어지고, 모르는 종을 토종으로 단정하지 않는 안전장치도 그대로 작동한다.

**키 노출은 Pl@ntNet 쪽 설정으로 막는다.** 설정 페이지에서 **"expose my API key"**를 켜고
**Authorized domains**에 앱 주소를 넣으면, 키가 요청에서 보이더라도 다른 사이트에서는 쓰지 못한다.
이 설정이 있으므로 **키를 숨기려고 서버나 프록시를 둘 필요가 없다.**
대신 **앱 주소가 바뀌면 허용 도메인을 다시 넣어야 한다.**
